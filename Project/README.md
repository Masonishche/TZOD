## Тема

Агент аналізу якості електроенергії — автоматизована система для потокового аналізу цифрового сигналу напруги, виявлення перешкод та фіксації відхилень (просадок та перенапруг).  
**Методи:** Цифрова обробка сигналів (Digital Signal Processing - DSP), фільтри Баттерворта 4-го порядку, ковзне вікно RMS.  
**Інтерфейс:** CLI (Command Line Interface).  
Агент самостійно оцінює рівень завад у мережі та динамічно приймає рішення щодо параметрів фільтрації та меж допусків.

---

## Джерело даних (Симуляція)

**Тип:** Синтетична генерація (Digital Twin)  
Для роботи агента програмно генерується математична модель мережі змінного струму:
* **Номінальна частота:** 50.0 Гц
* **Номінальна напруга:** 220.0 В (RMS)
* **Частота дискретизації:** 2000 Гц (2 кГц)

До ідеального сигналу штучно додаються:
1. Білий електромагнітний шум (задається користувачем).
2. Вищі гармоніки (3-тя [150 Гц] та 5-та [250 Гц]), характерні для імпульсних блоків живлення.
3. **Аномалія 1 (Sag):** Просадка напруги на 30% тривалістю 0.4 сек.
4. **Аномалія 2 (Swell):** Перенапруга на 25% тривалістю 0.3 сек.

## Архітектура агента

Агент функціонує за парадигмою **ReAct (Reason + Act)**:

| Компонент | Метод класу | Опис |
|---|---|---|
| Сприйняття | `generate_and_inject()` | Збір сирих даних, генерація шуму та ін'єкція аномалій |
| Діагностика | `diagnose()` | Оцінка відношення сигнал/шум (SNR) |
| Рішення 1 | `diagnose()` | Вибір параметрів цифрового фільтра (Зріз: 60Гц / 100Гц / Без фільтра) |
| Рішення 2 | `diagnose()` | Встановлення коридору допусків (±10% або ±15%) |
| Дія 1 | `apply_filter()` | Застосування ФНЧ Баттерворта (`scipy.signal.filtfilt`) |
| Дія 2 | `calculate_rms_and_detect()`| Розрахунок ковзного RMS та виявлення відхилень |
| Оцінка | `compute_metrics()` | Розрахунок метрик: Precision, Recall, F1-score |
| Візуалізація | `visualize()` | Побудова та збереження аналітичних графіків |

## Логіка прийняття рішень агента

### Рішення 1 — Цифрова фільтрація (DSP)

| Оцінка SNR (дБ) | Рішення агента (Дія) | Причина |
|---|---|---|
| SNR > 35 дБ | `none` (Без фільтрації) | Сигнал чистий, фільтрація не потрібна |
| 20 < SNR ≤ 35 дБ | `butter_low` (Зріз 100 Гц) | Стандартне очищення від ВЧ-шумів та 3/5 гармонік |
| SNR ≤ 20 дБ | `butter_high` (Зріз 60 Гц) | Агресивна фільтрація через сильне забруднення сигналу |

### Рішення 2 — Межі виявлення аномалій (Tolerance)

| Рівень шуму (STD) | Коридор допусків | Причина |
|---|---|---|
| ≤ 20 | ± 10% (ГОСТ) | Нормальні умови, стандартні жорсткі межі |
| > 20 | ± 15% | Високий базовий шум, розширення меж для уникнення хибних спрацювань |

## Метрики якості

| Метрика | Опис |
|---|---|
| **Precision** | Точність спрацювань: частка реальних аномалій серед усіх точок, на які зреагував агент. |
| **Recall** | Повнота виявлення: відсоток успішно знайдених аномалій від їх загальної реальної кількості. |
| **F1-score** | Збалансована оцінка, гармонічне середнє між Precision та Recall. |

## Висновок

Під час виконання даного проєкту я розробив автономного AI-агента для аналізу якості електроенергії (Варіант 21) та здобув практичний досвід у таких ключових напрямках:

* **Проектування архітектури AI-агентів:** Я на практиці засвоїв парадигму **ReAct** (Perception-Reasoning-Action). Замість написання жорсткого лінійного скрипту, я навчився створювати систему, яка самостійно сприймає середовище (оцінює рівень шуму через SNR), логічно міркує та приймає адаптивні рішення (динамічно підбирає параметри фільтрів та межі допусків).
* **Цифрова обробка сигналів (DSP):** Я опанував роботу з бібліотекою `scipy.signal`. Навчився проектувати та застосовувати цифрові фільтри Баттерворта 4-го порядку (`filtfilt`) для ефективного очищення часових рядів від високочастотного електромагнітного шуму та гармонік (150 Гц / 250 Гц) без спотворення фази корисного сигналу.
* **Оптимізація обчислень на Python:** Під час реалізації ковзного вікна для розрахунку RMS я відійшов від використання повільних циклів `for` на користь швидкої математичної згортки (`np.convolve`) з бібліотеки `numpy`. Це дало розуміння того, як оптимізувати алгоритми для роботи з потоковими даними в реальному часі.
* **Оцінка якості алгоритмів:** Я закріпив навички використання ML-метрик з `scikit-learn`. Робота над агентом дозволила на практиці побачити, як балансувати між **Precision** (уникнення хибних спрацювань на шум) та **Recall** (недопущення пропуску реальних просадок напруги) за допомогою динамічної зміни порогів виявлення.
* **Створення синтетичних даних (Digital Twins):** Здобув досвід програмної генерації математичних моделей фізичних процесів. Навчився симулювати ідеальний сигнал мережі (220 В, 50 Гц) та "забруднювати" його контрольованими аномаліями (Sag/Swell) для тестування алгоритмів у контрольованому середовищі.

Загалом, проєкт дозволив успішно поєднати навички програмування на Python, математичної статистики та обробки сигналів для створення повноцінного автоматизованого інструменту.
